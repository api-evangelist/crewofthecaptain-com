Crew of the Captain is a small software house that designs and builds web applications, marketplace add‑ons, and creative 3D tools. They work in clear, checkable steps, delivering projects with a focus on automation and AI‑assisted tooling. Their services include fast maintainable web apps, integrations for platforms like Zendesk and Atlassian, and procedural generators for game and design pipelines, all crafted by a steady crew of developers.

**Areas:** Software House · Web Development · Marketplace Apps · Creative Tools · Automation

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Crew of the Captain: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
